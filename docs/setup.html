Window Fan Control · 1.2.0

One observed state.
One shared controller.

Configure a Broadlink-controlled window fan with measured power feedback and continuous climate control. Public packages contain generic placeholders.

  1. Download the latest release.
  2. Set entity IDs, learned remote commands, schedule and thresholds in build.py, then run python build.py.
  3. Measure all nine fan states and configure shared calibration. Included wattage bands are examples.
  4. Replace existing fan packages, install the card JavaScript module, and use the matching generated card YAML.
  5. Check Home Assistant configuration, restart, refresh the dashboard, and observe operation.

Complete installation instructions · Policies and calibration

The former browser generator is retired. The versioned builder produces the current packages and updates every embedded hardware reference together. It runs locally and requires only Python's standard library.
