Den window fan controller

The supported setup uses one den package, persistent expected state, one serialized executor and the matching dashboard card. The v1.6.0 den climate policy and independent shared dehumidifier are preserved.

Public YAML contains generic examples. Confirm real entities, learned command names, startup behavior and timing, then generate a private installation package.

Update the card through the v1.7.0 HACS release, then install your privately customized combined fan/LED YAML package separately. HACS does not replace YAML packages. Do not install public generic mappings unchanged.
